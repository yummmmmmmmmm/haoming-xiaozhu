# 待替换素材收件箱（design-input）

这里是给你放「要替换的图片和图标」的地方，按**界面位置**分好了文件夹。
每个文件夹里都有一份 `_说明.txt`，写明：这个位置现在长什么样、对应哪段代码、建议尺寸。

## 怎么用

1. 打开对应文件夹，把图片拷进去（文件名建议用英文小写，如 `home.png`）
2. 全部放完，跟我说一声「素材放好了」
3. 我会：接上资源管线（新建 `public/assets/`、让构建自动复制到产物）→ 替换对应位置的 emoji / 渐变占位图 → 重新构建并部署给你看效果

> 现在项目里的图片**全部是运行时用「emoji + 渐变色」生成的 SVG**，一个真实图片文件都没有，
> 也没有 `public/` 目录。所以「接资源管线」这一步是必须的，我会一起做掉。

## 关于「整体风格」

你说参考图想改的是**整体风格** —— 补充一个好消息：这个项目的视觉基调相当集中。

配色、圆角、阴影几乎全在 `src/styles.css` 顶部的 `:root` 变量里（现在是「暖黄 + 奶茶棕 + 提莫西草绿」的 3D 潮玩治愈风）：

```css
--primary: #f5b71e;   /* 主色：明亮暖黄 */
--tan:     #e3b183;   /* 主体：荷兰猪奶茶棕 */
--green:   #9bc15a;   /* 点缀：提莫西草绿 */
--radius:  22px;      /* 大圆角 */
--shadow:  0 10px 26px rgba(196,146,52,.16);
```

所以改整体风格 = 改这一组变量 + 各处的间距/圆角细节，**不需要动结构**。
